IS1008 国际秩序与和平条件

单选题● 综合2025年重庆卷

问题背景

联合国成立于1945年，2025年为80周年。国际规则、国内政治、利益冲突和安全困境都会影响和平，不能把冲突归为唯一原因。

阅读材料

今年是世界反法西斯战争胜利暨联合国成立80周年。80年来，国际形势变乱交织，各种挑战和风险不断涌现。今天，人类又一次站在了团结还是分裂、对话还是对抗、共赢还是零和的十字路口。

背景知识

相关概念：联合国、集体安全、多边主义。

问题

历史和现实启示我们：

①不公平、不合理的国际规则和机制是国家间冲突的根源

②国际形势越是变乱交织，越要维护以联合国为核心的国际体系

③要团结一切爱好和平的国家和人民，反对霸权主义和强权政治

④发展是和平的基础，只有推动世界经济发展才能根除分裂与对抗

参考答案

C

解析

相关知识：联合国、集体安全、多边主义。

A 项

②与题设强调的国际合作方向一致；不公平规则可能加剧冲突，但①将其视为国家间冲突的根源，缺乏充分依据。

B 项

B的两项都把复杂过程单因化。规则和发展会产生影响，但不能据此说明一切冲突的起因或消除条件。

C 项

C成立。②强调依宪章合作，③强调和平解决分歧；实际行动的合法性仍须根据事实和适用规则判断。

D 项

D中的③成立，④不成立。增长不自动解决分配争议、军备竞赛或政治敌意，还需要制度与外交安排。

题解与方法

本题保留2025年的周年情境。联合国的规范地位、实际成效和成员国的行为是否合规，应分别讨论。
