WM9015 《雅典学院》与《圣礼论辩》：文艺复兴时代的新旧并存

单选题● 进阶2025年山东卷

问题背景

古典哲学与基督教神学可以在文艺复兴时期的艺术赞助中并置。

阅读材料

1508-1511年，拉斐尔在梵蒂冈宫签字厅的墙壁上为罗马教皇创作了《雅典学院》，画作描绘的是以柏拉图、亚里士多德为中心的人物群像。对面墙上是拉斐尔的另一幅壁画《圣礼论辩》，描绘了各个时代的著名神学家论辩圣礼的场景。

A 项

两幅壁画体现古典哲学与基督教神学的并置，但题目更强调同一时代不同思想传统并存。

B 项

古典哲学与神学并置反映文化发展具有连续性和复杂性。

C 项

两幅作品均为壁画，不能据此推出多种艺术形式融合。

D 项

并置不必然意味着正面冲突或斗争。
