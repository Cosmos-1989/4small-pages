HT1010 春秋至战国大臣来源的变化

单选题● 进阶2025年海南卷

问题背景

春秋战国时期诸侯竞争与政治制度发生变化。

阅读材料

春秋时期，大臣多为显赫贵族的子弟，他们的地位与生俱来，君主不能任意废除。战国时期，国君通过优厚条件招募贤士为官，任用期间加以考核，对大臣的提拔与罢免比较灵活。此种变化反映了：

背景知识

专题背景：春秋卿大夫与政治重组。

相关知识：生产力与生产关系、历史比较的方法。

C

解析

相关知识：生产力与生产关系、历史比较的方法、春秋卿大夫与政治重组。

A 项

选贤任能与任免变化显示官僚化趋势，但不足以证明制度最终确立。

B 项

材料对比贵族子弟世袭地位与国君招募、考核大臣，谈的是中央政治人员的选任，未提供地方郡县设置的证据。

C 项

战国列国竞争促使国君重视人才与行政、军事能力；以待遇招募、按表现考核官员，有助于组织资源和增强国家实力。

D 项

依靠才能选任而非身份世袭，反映宗法贵族政治受到冲击。
