细胞类型与细胞状态

概念笔记增殖与发育

同一种细胞在炎症、营养变化或刺激后可暂时改变表达，未必发生了谱系转换。判定新的分化类型，通常需要多个分子标志、形态和功能的一致证据，还要检验变化能否维持。单细胞表达测序能揭示异质性和候选过渡状态，但计算得到的相似性轨迹并不自动证明真实祖先后代关系，仍需谱系标记等实验支持。
