生产通量与现存生物量

概念笔记生物圈

生产通量是单位时间形成有机物或固定碳的速率，现存生物量是某时点的生物物质存量。例如前者可用g C m−2 yr−1\mathrm {g\ C\ m^{-2}\ yr^{-1}}g C m−2 yr−1，后者可用g C m−2\mathrm {g\ C\ m^{-2}}g C m−2；比较须统一面积及干重或碳量口径。

净初级生产量扣除了生产者自身的呼吸，生产者现存量的变化还受摄食、死亡和输出影响，所以NPP不等于其存量的简单增量。

浮游植物可因快速生长、繁殖并被摄食而维持较小存量，仍持续支持较大生产通量。森林存量很大，其NPP也未必高于所有草地。因此生物量金字塔可能倒置，不能直接代替能量通量金字塔。
