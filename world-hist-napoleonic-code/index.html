拿破仑与民法典

概念笔记近代世界

1799年拿破仑通过政变掌权，1804年称帝并颁布民法典。法典规范财产权与契约，影响欧洲及其他地区的法律编纂。

法典强调法律统一，却强化丈夫与父亲在家庭中的权力；法国1802年在部分殖民地恢复奴隶制。欧洲战争既传播制度变革，也包含征服、征兵和掠夺。

民法典保护财产及合同，删除不少等级特权；婚姻和家庭章节又约束已婚妇女的法律自主。1812年远征俄国损失惨重，1815年滑铁卢战败后拿破仑再次退位。
