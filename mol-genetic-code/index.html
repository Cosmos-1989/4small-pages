遗传密码

概念笔记基因表达

密码子是mRNA上按5′到3′读取的三个连续核苷酸。起始位点确定阅读框；例如AUG、GCU、GAA、UAA依次表示起始甲硫氨酸、丙氨酸、谷氨酸和终止。平移一个碱基就改变分组。

标准密码有64种三联体，61种指定氨基酸，UAA、UAG、UGA终止；多个密码子可指定同一种氨基酸，称为简并性；同一密码子在既定密码体系及通常翻译条件下有确定的含义。终止由释放因子识别，tRNA须由相应酶装载氨基酸，再通过核糖体完成翻译。

分析DNA时须先确认模板链、编码链及方向，再确定转录区、剪接方式与阅读框。NCBI列有线粒体等替代密码表，特殊机制也可重解释某些终止密码子；判读须匹配生物和细胞器。
