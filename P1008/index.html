P1008 ¹⁸O 标记实验：确定光合作用释放的氧的来源

单选题● 基础经典实验（Ruben & Kamen, 1941）

题目背景

总反应式 6 CO2+6 H2O→C6H12O6+6 O26\,\mathrm{CO_2}+6\,\mathrm{H_2O}\rightarrow\mathrm{C_6H_{12}O_6}+6\,\mathrm{O_2}6CO2​+6H2​O→C6​H12​O6​+6O2​ 无法表明 O2\mathrm{O}_{2}O2​ 的归属。Ruben 与 Kamen（1941）以 18O{}^{18}\mathrm{O}18O 同位素标记为此提供了直接证据。

阅读材料

在短时间示踪、排除标记氧与水大量交换的条件下，向两组绿色植物分别供给 H218O\mathrm{H}_{2}{}^{18}\mathrm{O}H2​18O 与 C18O2\mathrm{C}{}^{18}\mathrm{O}_{2}C18O2​（其他条件相同且适宜），检测两组释放的 O2\mathrm{O}_{2}O2​ 中是否含有 18O{}^{18}\mathrm{O}18O。

背景知识

同位素标记法的原理：同一元素的各种同位素化学性质相同，可借此追踪原子的转移路径；18O{}^{18}\mathrm{O}18O 是氧的稳定同位素（无放射性，需质谱检测）。水的光解：

2 H2O→4 H++4 e−+O22\,\mathrm{H_2O}\rightarrow 4\,\mathrm{H}^+ + 4\,\mathrm{e}^- + \mathrm{O_2}2H2​O→4H++4e−+O2​

解析

相关知识：氧的同位素示踪、水的光解。

A 项

相反——H218O\mathrm{H}_{2}{}^{18}\mathrm{O}H2​18O 组释放的 O2\mathrm{O}_{2}O2​ 含 18O{}^{18}\mathrm{O}18O，因为 O2\mathrm{O}_{2}O2​ 来自水的光解。

氧同位素示踪比较氧来源。

B 项

在题设的示踪条件下，释放的 O2\mathrm{O}_{2}O2​ 直接来自水的光解，而非供给的 C18O2\mathrm{C}{}^{18}\mathrm{O}_{2}C18O2​；CO2\mathrm{CO}_{2}CO2​ 中的 18O{}^{18}\mathrm{O}18O 可进入其他产物或发生氧交换，不能笼统说只进入糖类。

氧同位素示踪比较氧来源。

C 项

在短时间示踪并排除标记氧与水大量交换的条件下正确：光反应直接释放的 O2\mathrm{O}_{2}O2​ 来自水的光解，不直接来自外加 CO2\mathrm{CO}_{2}CO2​。

氧同位素示踪比较氧来源。

D 项

在题设的短时示踪条件下，水标记组释放的 O2\mathrm{O}_{2}O2​ 含 18O{}^{18}\mathrm{O}18O；若示踪时间足以发生显著水—二氧化碳氧交换，则应另行分析标记分配。

氧同位素示踪比较氧来源。

题解与方法

同位素示踪的核心是"原子守恒与去向分离"。同类应用：14C{}^{14}\mathrm{C}14C 标记 CO2\mathrm{CO}_{2}CO2​ → 追踪卡尔文循环的中间产物；Meselson 与 Stahl 以 15N{}^{15}\mathrm{N}15N 标记细菌 DNA → 证明 DNA 半保留复制。相关笔记：¹⁸O 标记实验、水的光解。
