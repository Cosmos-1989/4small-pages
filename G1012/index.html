G1012 阿巴斯平原地下水位下降的影响

单选题● 综合2026年四川卷

问题背景

干旱区封闭含水空间的灌溉会改变地下水位和盐分迁移；水位变化、流速和盐度不能混作一个指标。

阅读材料

阿巴斯平原为西亚某农业区，年均温约24.5∘C24.5^\circ \mathrm {C}24.5∘C，年均降水量约250毫米，地下为封闭的储水空间，地下水埋藏深度大。1984-2006年，该地抽取地下水灌溉，地下水位下降。2006年后，该地引用平原外6.7千米处水库的淡水大面积灌溉，地下水位持续上升，地下水盐度不断增加。下图为1984-2006年该平原地下水位下降深度等值线图。据此完成下面小题。

背景知识

读图所需概念见地下水流动与盐分迁移、灌溉与盐分管理。

地下水流速取决于水力坡降和含水层渗透性；水位整体下降本身不能确定流速升降。灌溉淋洗可把土壤与包气带盐分送入地下水，需设置排水出路。

问题

1984-2006年，该平原地下水位下降导致地下水（   ）

参考答案

C

解析

相关知识：灌溉盐分迁移、自流灌溉。

A 项

埋深增大通常减弱浅层地下水直接蒸发，不会因水位下降而必然增加蒸发。

B 项

封闭含水空间的地质边界不会因抽水缩小；若“集水区”指井的捕获范围，则另需流场资料，原表述有歧义。

C 项

在渗透性不变且区域平均水力坡降减小的条件下，按达西定律可选 C；图中仅有累计降深，单凭水位下降不能判定流速。

关联知识：灌溉盐分迁移。

D 项

抽水降低地下水位，若原先向河流排泄，一般会削弱基流；是否发生河水倒灌还要看相对水位，不能得出补给增多。

题解与方法

正确答案：C。

选择 C 须以区域平均水力坡降减小、渗透性不变为前提。地下水流速由水力坡降和渗透性共同决定；若缺少这项条件，题图证据不足以唯一确定 C。
