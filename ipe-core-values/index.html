社会主义核心价值观

概念笔记国家与公民

社会主义核心价值观是中国现行课程与政策中的规范框架。2013年相关意见将其概括为国家层面的富强、民主、文明、和谐，社会层面的自由、平等、公正、法治，以及个人层面的爱国、敬业、诚信、友善。宪法第24条规定国家倡导社会主义核心价值观。

这些概念分别指向制度目标、社会关系和行为要求，层面之间相互关联。例如，诚信需要个人如实表达，也需要交易制度保护守信者；公正涉及个人判断，也涉及规则、程序与资源分配。

价值词本身不直接给出每一处境的答案。解释某项要求，仍须说明对象、理由、可行方式和权利边界，并处理不同价值之间的张力；参见价值冲突与公共利益。

比较视角

《世界人权宣言》以人的尊严、平等和权利为组织框架，与中国核心价值观在自由、平等和公正等问题上具有可比较内容。前者是联合国大会通过的国际宣言，后者是中国课程与政策的价值体系，词语对应不等于法律地位或解释完全相同。

拓展阅读

中共中央办公厅《关于培育和践行社会主义核心价值观的意见》（2013）：阅读三个层面的原始政策表述。

《中华人民共和国宪法》（2018年修正）：第24条提供宪法语境。

联合国《世界人权宣言》（1948）：对照第1、2、29条，比较尊严、平等与公共生活义务的表述。
