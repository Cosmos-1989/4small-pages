IC1012 生产方式与社会结构

单选题● 综合2022年湖南卷

问题背景

经济基础指一定社会占主导地位的生产关系的总和。国家组织、法律观念和意识形态与其相联系，但不同层次之间存在中介与反作用。

阅读材料

恩格斯说：“每一历史时代主要的经济生产方式和交换方式以及必然由此产生的社会结构，是该时代政治的和精神的历史所赖以确立的基础，并且只有从这一基础出发，这一历史才能得到说明。”

背景知识

相关概念：经济基础与上层建筑、生产力与生产关系、生产方式。

问题

从中可以认识到：

①每一历史时代的各种经济生产方式都会产生相应的上层建筑

②物质生活的生产方式制约着整个社会生活、政治生活和精神生活的过程

③每一历史时代，人们调整社会关系的实践构成了社会生活的政治领域

④一个时代的国家设施、法的观点是从物质生活资料生产的基础上发展起来的

参考答案

C

解析

相关知识：经济基础与上层建筑、生产力与生产关系、生产方式。

A 项

①原文强调时代主要的生产交换方式，不能据此推断每一种局部方式都各自决定上层建筑。②物质生活生产方式制约社会、政治和精神生活，符合题意。

B 项

①原文强调时代主要的生产交换方式，不能据此推断每一种局部方式都各自决定上层建筑。③调整社会关系的各种实践不能全部归入政治领域。

C 项

②物质生活生产方式制约社会、政治和精神生活，符合题意。④国家制度及法律观念应从相应的物质生活关系中作历史解释。

D 项

③调整社会关系的各种实践不能全部归入政治领域。④国家制度及法律观念应从相应的物质生活关系中作历史解释。

题解与方法

经济基础与上层建筑不是经济活动与一切非经济活动的简单二分。文化现象的广义范围更大，不能因它具有意义或规范内容就一律放入同一种上层建筑形式。

生产方式包括生产力与生产关系的联系。

拓展阅读
  • 马克思：《政治经济学批判》序言（1859），生产方式与社会意识
  • 马克思：《关于费尔巴哈的提纲》，实践与认识的关系
  • 恩格斯：《共产党宣言》1888年英文版序言，主要经济生产和交换方式与社会历史解释
