WA8022 英格兰土地买卖法令

单选题● 进阶2025年北京卷

问题背景

结合时代背景和材料证据，辨析历史现象与解释。

阅读材料

1290年，英王爱德华一世颁布《土地买卖法令》，禁止以再分封的方式转让土地，规定自由人持有的土地买卖自由，但购地者要承担土地附着的原有封建义务。

背景知识

英格兰土地转让。

问题

这一法令：①意在保护封建领主利益②加重了农奴的经济负担③冲击了英国的封建制度④奠定了民族国家的基础

参考答案

C

解析

相关知识：英格兰土地转让。

A 项

②针对农奴负担，材料仅涉及自由人土地。

B 项

④民族国家形成不能归因于单一法令。

C 项

①原有封建义务继续承担，有利于领主；③土地转让方式调整可能推动土地流通，冲击部分既有依附关系，但法令并未废除封建义务。

D 项

②④均无法由材料成立。
